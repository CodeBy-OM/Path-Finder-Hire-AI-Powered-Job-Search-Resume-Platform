# 🚀 Path Finder Hire – AI Powered Job Search & Resume Platform

Path Finder Hire is an AI-powered platform designed to help job seekers discover relevant opportunities and improve their resumes using intelligent recommendations. The platform connects candidates with job listings while providing tools to analyze resumes, match skills with job descriptions, and streamline the job search process.

The goal of this project is to simplify the hiring journey by combining modern web technologies with AI-driven insights.

---

## ✨ Features

### 👤 Job Seeker

* Create and manage a professional profile
* Upload and manage resumes
* AI-powered resume analysis and suggestions
* Search and filter job opportunities
* Smart job recommendations based on skills
* Track job applications

### 🤖 AI Capabilities

* Resume skill extraction
* Job description matching
* AI-based recommendations
* Resume improvement suggestions

### 🧑‍💼 Recruiter / Employer

* Post job listings
* Search candidates by skills
* Review applicant profiles
* Manage hiring pipeline
